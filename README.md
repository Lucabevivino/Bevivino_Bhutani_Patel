## Overview

RacePulse is a distributed platform that collects Formula 1 session data from
[OpenF1](https://openf1.org/) and makes it available to heterogeneous consumers
(racing enthusiasts and third-party applications) through a GUI and an API.

This repository contains the full Software Engineering 2 project, spanning both
the Requirement Engineering & Design (R&DD) and the Implementation & Testing
(I&T) assignments.

## Repository structure

- `RASD/` — Requirement Analysis and Specification Document (LaTeX)
  - `chapters/` — one `.tex` file per chapter
  - `alloy/` — Alloy formal model (`.als`)
  - `figures/` — UML and Alloy diagrams
- `DD/` — Design Document (LaTeX)
  - `chapters/` — one `.tex` file per chapter
  - `figures/` — architectural diagrams
- `IT/` — prototype implementation (backend + frontend)
- `ITD/` — Implementation & Test Deliverable (LaTeX)
- `ATD/` — Acceptance Test Deliverable (LaTeX)
- `DeliveryFolder/` — final versioned PDFs (`RASDv1.pdf`, `DDv1.pdf`, `ITDv1.pdf`, `ATDv1.pdf`)
